# Quick start

Use Node.js 24, run `npm ci`, then `npm run dev`. Open the Vite URL to see the build-time shared shell. No Supabase credentials are needed for the current portfolio; newsletter collection is disabled.

For production verification, run the commands in [README.md](README.md). The browser suite requires a built site and Chromium, and mocks contact delivery. Deployment is gated by the shared quality workflow.
