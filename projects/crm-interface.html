Business workflow / Interface prototype

Customer relationship management.

Exploring customer, sales, and support workflows through a collection of connected interface screens.

Public projectSource reviewed: October 24, 2026View repository

The problem

Customer information often spans several tasks: reviewing contacts, tracking sales, and handling support. This project explores how those tasks can be organized into a navigable interface.

What the source shows

The reviewed repository contains HTML interface files, including contact, sales, marketing, support, and ticket-detail views. It is a frontend prototype. The README identifies backend integration as future work.

Implementation choices

Separate views make the workflow easy to inspect one task at a time. The shared navigation connects these views, providing a starting point for discussing information architecture before committing to a data model or backend.

Limitations and status

The public code does not establish a working FastAPI or PostgreSQL backend, server-side authentication, persistent customer records, or a deployed client CRM. Login and registration screens alone do not provide authentication.

What would come next

Before connecting real customer data, define the workflow, roles, data model, access controls, and integration requirements. A useful first increment could focus on a single support flow.
