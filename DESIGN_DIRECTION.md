# MNXTR — Obsidian Field Manual

The portfolio is for prospective freelance clients considering AI and workflow automation. Preserve a calm, technical character: near-black surfaces, mint actions, thin rules, readable prose, and compact monospace labels. The display voice remains monospaced; body copy uses the existing system font stack. No new font service is required.

The main promise is “Practical AI for your business workflows.” Services explain possible engagements; project pages establish what has actually been implemented. Avoid unsupported deployment, business-impact, benchmark, client, or graduation claims.

The homepage follows services → public evidence → process → FAQ → project brief. “Send a project brief” is the primary action. Blog, résumé, and Security Radar remain secondary routes. Case studies use source links and clearly labeled workflow schematics rather than illustrative images presented as product screenshots.

Use semantic color variables in both themes. Text, links, inputs, and focus rings must remain legible. Inline links retain underlines. All content starts visible; the optional desktop ornament is decorative, idle-loaded, paused offscreen, and absent on mobile or reduced motion. Keep the native pointer and native scrolling.

Validate at 320, 390, 768, and 1440 pixels; cover text enlargement, keyboard navigation, no JavaScript, dark/light themes, and accessible error states. Shared navigation and footer are injected at build time so the deployed HTML works without client rendering.
